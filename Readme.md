# Goal
This application helps manage chapter wise blog allowing user to view few blogs in starting without login in then it asks them \
to enter their basic details for reading further blog. It will also integrate email and whatsapp marketing to send messages to \
users who have subscribed to blog. 
The application also contains a utils folder which generalizes the output format which can be directly used in frontend.
Application uses analytics to store the usage of person's data (seprate microservice). 
Application will have test cases code and tracing
Application will have rate limiting
